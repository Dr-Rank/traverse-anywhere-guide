Explore the traversal tools and the feature set, then follow the setup route for your project. **CMC, GMC, Network Prediction Mover and Chaos Mover** are all first-class movement choices.

| Feature group | What you will find |
| --- | --- |
| Character setup | A setup window with per-row checks and fixes, a guided setup wizard with live import progress and restart recovery, and copying of engine example pawns. Keep your locomotion or generate a full-animation character. |
| Animation libraries | **True offline retargeting: no dynamic runtime retargeting.** Target-skeleton animation assets, motion matching, pose history and choosers. |
| MetaHumans | Set up a [compatible MetaHuman body](#use-a-metahuman-from-the-game-animation-sample) with baked GASP animations. Use Kellan from the sample or assemble your own MetaHuman as a playable pawn. |
| Styles and traversal | Neutral and Relaxed styles; hurdles, vaults, mantles and climbs; motion warping. |
| Contact and recovery | Hand goals, foot clearance and blending back to locomotion. |
| Objects and proxies | One-click object setup, level conversion, fitted surfaces, filters, collision and rebuilding. |
| Movement and multiplayer | **CMC / GMC / Network Prediction Mover / Chaos Mover**, each with native integration. |
| Optional physical features | Three slide types, ragdoll, knockdown and get-up, death ragdolls, hit reactions and injuries. |
| Paired interactions | Shove, tackle and takedown with participant coordination. |
| First-person presentation | An owner-only body, head following through physical motion, configurable look limits and Blueprint camera functions. |
| Your own animations | Retarget your own sequences and montages onto another supported skeleton, offline, with finger, hand, knee and vertical-motion corrections. |
| Inspection and integration | Ledge diagnostics, custom queries, traversal events and a [Blueprint reference](#blueprint-reference). |
